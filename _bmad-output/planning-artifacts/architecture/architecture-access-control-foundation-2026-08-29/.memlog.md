- (constraint) Parent architecture AD-1 requires independently human-approved Stage-1 scenarios, then independently approved red HTTP E2E, before production code; this local spine cannot weaken that gate.
- (constraint) Parent AD-2, AD-3, AD-9, AD-10, AD-11, AD-12, AD-14, and AD-19 bind this scope: hexagonal code, real HTTP E2E, facade-only authorization, bulk/live audience resolution, typed relationship facts, fail-closed behavior, established route conventions, and PP semantics.
- (decision) The two-day foundation owns only Access Control Phase-0 audience derivation: Self, live direct Reporting, direct assigned People Partner, Colleague fallback, empty bulk short-circuit, and fail-closed broken/orphaned facts. It does not own User Management routes, response projection, UI, section/matrix decisions, Project, Department, PP HR-line, or functional permission evaluation.
- (decision) User Management remains the sole owner of the HTTP route and response projection. The Access Control foundation exposes a port/facade to be consumed by an existing or future User Management endpoint; it must not change User Management files.
- (question) Integration blocker: no identified User Management endpoint and response contract currently consumes the future facade. Before valid Stage-1 HTTP scenarios and Stage-2 E2E can be authored, the UM owner must name the route, request identity source, response-level observable outcome, and commit/branch that will wire it.
- (direction) PP mutation, journal details, scheduled departure, full-profile mapping, Project, Department, and timetracker decisions are excluded from this foundation. Their open product/architecture questions do not block the Phase-0 audience derivation, but may not be pulled into its implementation.
- (event) Decision review started on fast path at user request; decisions are inherited from existing reality or explicitly bounded as an open integration contract.
- (constraint) Reality check: User Management already has GET /users/:id protected by RequireFeatureForTarget and AccessControlPort.isAllowedForTarget. It is bound to InterimAccessControlAdapter, whose target check returns Boolean(userId); it is not the real facade. The candidate integration endpoint is therefore known, but the UM-owned port replacement and observable contract are not approved.

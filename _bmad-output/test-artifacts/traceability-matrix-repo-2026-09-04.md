## Method & Limits

- **Traceability model:** a criterion counts as case-traced when its id appears in the `it()` title, **any enclosing `describe()`**, or an adjacent comment — matching how Jest composes a full test name.
- **Red/green:** derived from production-code presence at HEAD (routes, models, facade methods), not from header prose, which was found stale in both directions.
- **Limit — nothing was executed.** `services/backend/node_modules` is absent and `docker-compose.yml` needs a `LOCALSTACK_AUTH_TOKEN` from an uncommitted `.env`. This run can establish that a test *cannot* pass; it never establishes that one *does*.
- **Limit — frontend unassessed.** See F2. `ui_journey_status` and `ui_state_status` are `UNTRACED`, not `not_applicable`.

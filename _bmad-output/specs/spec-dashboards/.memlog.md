- (decision) Dashboards context composes four fixed read models (UM, DM, PM, PP) from owning-context queries; AccessControl resolves authorized targets before aggregation; no generic dashboard/widget framework (PM/AD-33, dashboards.md).
- (decision) Dashboard customization affordances (customize mode, widget catalog, drag/remove handles, custom dashboards tab) are explicitly excluded per SD-1 and PM/AD-33.
- (decision) Dashboard stories deliver role-scoped shells, fixed read-model contract, and source-backed widgets only; unavailable source FRs render explicit degraded/empty states without fake data or fabricated zeros (SD-2, PMC-E2-S2.2).
- (decision) Epics split on PRD grouping axis: people-grouped (UM, PP) in Epic 2 vs project-grouped (DM, PM) in Epic 3 (SD-6).
- (decision) Epic 3 project-grouped dashboards remain blocked on TT-IDENTITY-01 P0 with no stories authored (SD-7).
- (decision) Authorization entrypoint is AccessControl facade only: isAllowed for functional permission checks, resolveAudiences for target scoping; fail-closed on absent grants (PM/AD-9, PM/AD-10).
- (decision) Unit Manager scope resolves transitively through Reporting-line direct reports-to graph; People Partner scope resolves through direct assigned People Partner relationship; no cross-graph merging (PM/AD-10).
- (decision) Headcount widget counts exactly active employees in resolved scope, excluding dismissed employees and request-time due departures, rendered in {typography.data-stat} mono (PM/AD-16, PM/AD-20, PM/AD-22, PMC-E2-S2.1).
- (decision) People table consumes Epic 1 shared row read model with per-target audience tier projection; leak verification delegated to shared projection matrix (PM/AD-34, PMC-E2-S2.1).
- (decision) People Partner dashboard contains no resourcing block, slot, counter, or placeholder by construction (PM/AD-33, PRD FR-18, PMC-E2-S2.3).
- (decision) Explicit unavailable states key on source FR availability provenance; never output 0, —, empty charts, or fake data for unavailable sources (SD-2, PMC-E2-S2.2).
- (decision) A legitimate measured zero is rendered as 0 in {typography.data-stat} mono with .wscope footer and remains visually distinct from unavailable state; empty scope renders .emptyst empty state (PMC-E2-S2.2).
- (decision) Preset tab strip in Epic 2 contains Unit Manager and People Partner presets only; Delivery Manager and Project Manager presets absent until Epic 3 (PMC-E2-S2.1, PMC-E2-S2.3).
- (decision) Grouping dimension in Epic 2 is people grouping active; department grouping is gated behind PMC-E2-S2.4 (PMC-E2-S2.1, PMC-E2-S2.4).
- (decision) UX chrome uses .pghd band with eyebrow 'WORKSPACE / DASHBOARDS', {colors.stretch-blue} accent tick, .prov tag, .wscope footer in mono uppercase stating evaluated access policy, and Skeleton placeholders (DESIGN.md, EXPERIENCE.md).
- (decision) Frontend data contract decouples React UI from backend HTTP availability via query/hook -> data-source interface -> mock/local implementation now -> HTTP/API implementation later, with staleTime: 0 and actor-scoped cache keys (PM/AD-25, PMC-E2-S2.2).
- (capability) CAP-1 (PMC-E2-S2.1): Unit Manager Dashboard Scope, Headcount, and People Table — Unit Manager opens dashboard scoped to resolved Reporting-line population, viewing headcount excluding dismissed and tier-projected people table.
- (capability) CAP-2 (PMC-E2-S2.2): Explicit Unavailable Widget States — Slots and columns with uncovered source FRs declare availability from source provenance and render explicit unavailable states; legitimate measured zeros render as 0 in data-stat mono.
- (capability) CAP-3 (PMC-E2-S2.3): People Partner Dashboard — People Partner opens dashboard scoped to assigned PP caseload with tier-projected people table and HR widgets, with resourcing absent by construction.
- (constraint) Constraint: No generic dashboard engine, widget catalog, drag/drop, customize mode, or configurable layout (PM/AD-33, SD-1).
- (constraint) Constraint: Fail-closed authorization via AccessControl facade; isAllowed returns false for unapproved grants with no relationship-derived fallback (PM/AD-9, OQ-PERM-01).
- (constraint) Constraint: PP dashboard must not contain any resourcing block, slot, counter, or placeholder by construction (PM/AD-33, PRD FR-18).
- (constraint) Constraint: Unavailable sources must never be represented as 0, —, empty charts, or fabricated data (SD-2, PMC-E2-S2.2).
- (constraint) Constraint: Measured zero must remain distinguishable from unavailable state and must never be suppressed (PMC-E2-S2.2).
